# Rare cook meme cue

`youre-goddamn-right.mp3` is the short requested Breaking Bad dialogue excerpt,
“You’re goddamn right,” sourced from
[Myinstants](https://www.myinstants.com/en/instant/youre-goddamn-right-breaking-bad-22260/).
Downloaded from `https://www.myinstants.com/media/sounds/youre-goddamn-right.mp3`.
Only the engine's Flawless Blue result triggers the voice. Playback is local;
no third-party requests occur during play. This is a dialogue excerpt, not an
original or procedurally generated asset.

## Background music

The desert-blues background music (“Dust and Static”) has no audio file here. It is
composed in code in `audio.js` (notes, rhythm and synthesis) as original work for
this game, and is synthesized live with Web Audio oscillators and seeded noise. It
contains no sample, recording, vocal or melody from the television series or any
other source. Only `youre-goddamn-right.mp3` above is third-party material.
